Monitor Plus — 额度与算力监控

把 GLM / Codex 订阅额度与多台服务器的 CPU、GPU 和显存状态，集中放进桌面悬浮窗。

支持置顶、拖动和折叠为紧凑模式，随时查看额度用量、重置倒计时以及服务器负载。通过单文件 Python Agent 接入多台机器，集中展示 CPU、内存及 NVIDIA GPU 的利用率、显存和温度；提供 Windows 安装包。

Keep GLM Coding Plan and Codex usage, reset countdowns and server workloads beside your work. The floating window can stay on top, be moved or collapsed into a compact view. A Python agent packaged in one file supplies CPU, memory and NVIDIA GPU metrics from multiple machines, including GPU utilization, memory usage and temperature. Windows installers are available from GitHub Releases.

Tauri 2 · Rust · React · TypeScript

Digitizer Plus — 图表数据提取工具

把论文里的曲线，变成可分析的数据：导入图表、标定取点，再导出 CSV 继续分析。

导入论文配图、扫描曲线或实验图像，标定已知坐标后沿曲线点击取点，即可导出 CSV 继续分析。支持 XY 线性与对数轴、极坐标和三元相图，取点结果实时换算显示，图像处理与坐标计算全部在本机完成，提供 Windows 和 macOS 安装包。

Turn chart images from papers and scans into data you can analyze. Import a plot, calibrate known coordinates, then click along curves to sample points and export them as CSV. Digitizer Plus supports linear and logarithmic XY axes, polar coordinates and ternary diagrams, shows converted values as you work, and processes everything locally. It runs on Windows and macOS.

Agent Skill · Browser automation · Fare evidence

flight-fare — 航班全价查询与证据整理

让 AI agent 整理航班全价经济舱比价证据，保留官网原始截图与查询记录。

按航班号、日期和航段查询航司官网，核验页面明示的舱位与价格，保存原始截图和结构化汇总，为报销比价留存可追溯证据。内置多家航司的站点经验，可配合具备浏览器能力的 Codex、Claude Code 等 AI agent 使用。

An Agent Skill for collecting full-fare economy price evidence from airline websites. Given a flight number, date and route, the agent checks the displayed fare and cabin, saves original screenshots and produces a structured summary. Guidance for individual airlines supports repeatable queries, while the saved records help prepare reimbursement comparisons. It works with Codex, Claude Code and other AI assistants that can operate a browser.
