Monitor Plus — 额度与算力监控

悬浮窗集中展示 GLM / Codex 额度用量、重置倒计时和多台服务器 CPU / GPU 状态，支持置顶拖动与折叠，把核心运行指标固定在桌面旁边。

The floating window shows GLM and Codex quota usage, reset countdowns and CPU or GPU status from multiple servers. It can stay on top, be dragged, and collapse for a compact desktop view.

Tauri 2 · Rust · React · TypeScript

Digitizer Plus — 图表数据提取工具

从论文配图或扫描图像标定已知坐标并沿曲线取点，导出 CSV；覆盖线性、对数、极坐标与三元相图，换算结果实时显示，处理过程全部在本机。

Calibrate chart images, pick points along curves, and export CSV for analysis. Linear, logarithmic, polar and ternary axes are supported, with live conversion and fully local processing.

flight-fare — 航班全价查询与证据整理

按航班号、日期和航段查询航司官网，核验全价经济舱的页面明示价格；保存原始截图和结构化证据，供报销比价追溯，可配合浏览器 AI agent 使用。

Given a specific flight number, date and route, agents verify full-fare economy prices on airline websites. Original screenshots and structured evidence support traceable reimbursement comparisons.
