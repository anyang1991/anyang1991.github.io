Digitizer Plus — 图表数据提取工具

一款现代、跨平台（Windows / macOS / Linux）的桌面工具：从论文截图和扫描曲线中提取数据，把像素还原成数字 —— "converting pixels into numbers"。

从图表图片里手动取点，实时换算成数据坐标并导出 CSV。支持三类图表：XY 图（两轴独立线性/对数标定）、极坐标图（圆心-半径-角度三点标定，0–360 与 ±180 惯例）、三元相图（三顶点重心坐标，材料/化学/地质常用）。滚轮缩放、画布平移、完整撤销栈，安装包仅 ~15 MB，内置 GitHub Releases 签名自动更新。向 Engauge Digitizer 致敬 —— 全部代码为 Rust + TypeScript 独立重写（MIT）。

Calibrate and pick points on chart images, export to CSV. XY (linear/log per axis), polar (center–radius–angle, 0–360 and ±180 conventions) and ternary diagrams are supported, with wheel zoom, canvas panning and a full undo stack. Packaged with Tauri 2 at ~15 MB, signed auto-updates via GitHub Releases. A ground-up Rust + TypeScript rewrite inspired by Engauge Digitizer (MIT).

flight-fare — 航班全价查询技能 ✈️

面向 AI agent 的查询技能（agentskills.io 规范）：在航空公司官网查询指定航班的全价经济舱价格，保存原始截图与查询记录，供机票报销比价参考。

一套可复用的查询流程，而非爬虫：按技能指引在航司官网核对全价与 Y 舱价格并留存原始截图，保证证据可追溯。支持 Codex、Claude Code、ZCode 等宿主（浏览器能力由宿主提供，可配 Playwright MCP / chrome-devtools MCP / web-access），git clone 进 skills 目录即可安装。

A reusable query procedure — not a scraper — for verifying full-fare economy and Y-class prices on airline websites, keeping original screenshots as traceable evidence. Works with Codex, Claude Code, ZCode and other hosts (browser tooling supplied by the host, e.g. Playwright MCP or chrome-devtools MCP). Install by cloning into your skills directory.
