# Yang An (安洋) — Personal Website

This repository contains Yang An's independent personal website, available at [anyang.space](https://anyang.space).

The site is built as static HTML, CSS and JavaScript and does not require a Jekyll build step.

## Local preview

Run one of the following commands from the repository root, then open the address shown in the terminal:

```bash
npx --yes serve .
# or
python -m http.server 8080
```
